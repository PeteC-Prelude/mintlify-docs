The Origin agent supports latest versions of Windows 10, Windows 11, Windows Server 2022\+ and macOS 13 (Ventura) or later. The agent can be installed manually by an administrative user or it may be deployed using standard MDM/Management tools.

The agent runs as a service and includes the core agent and a watchdog service.

## Supported platforms

| Platform | Minimum version |
| --- | --- |
| Windows 10 | Latest builds |
| Windows 11 | Latest builds |
| Windows Server | 2022 and later |
| macOS | 13 (Ventura) or later |
