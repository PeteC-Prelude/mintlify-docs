# Source: https://support.originhq.com/docs/mdm-deployment-guides

The following MDM deployment methods have been tested and fully documented. Each method has its own page with detailed step-by-step instructions:

1. [**Windows Origin Agent via Intune**](https://support.originhq.com/docs/windows-via-intune)
2. [**macOS Origin Agent via Intune**](https://support.originhq.com/docs/macos-via-intune)
3. [**macOS Origin Agent via Jamf**](https://support.originhq.com/docs/macos-via-jamf)
4. [**macOS Origin Agent via Tanium**](https://support.originhq.com/update/docs/tanium-deployment-macos-agent)

> 📘
> 
> ### 
> 
> **Deployment package files**
> 
> The macOS deployment guides require a bundle of configuration profiles and install scripts. Download the latest set from [drive.google.com — Origin MDM Guides](https://drive.google.com/drive/folders/1r3PYJdVMgnTVjzyJqzKvys8rTFqWsKKF).

> 📘
> 
> ### 
> 
> **Note**
> 
> For manual installation instructions on macOS and Windows, refer to the **macOS Agent Installation** and **Windows Agent Installation** pages. MDM deployment is recommended for fleet-scale rollouts where per-endpoint manual installation is not practical.
