# Source: https://support.originhq.com/docs/skills

**Skills** are uploadable units of behavior that you make available to Origin. Once a skill is uploaded, it can be referenced anywhere Origin acts on your behalf — in the chat interface, in agent runs, or as part of a workflow.

![Skills view — empty state](https://files.readme.io/9f430daa83f5d5362a83d619b875084cd85316ad360e3cc7218f75b7233f16dd-Skills.png)

## 

At a glance

- **Skills list** (center) — every skill uploaded to your tenant. Shown here in its empty state with the prompt _No skills yet — upload your first._
- **\+ Upload skill** (top right) — primary action for adding a new skill.
- **Upload your first skill** (center button) — same action surfaced in the empty state for first-time setup.
- **Search skills…** — type-ahead search across skill name and description once you have some uploaded.
- **Include archived** toggle (top right) — show or hide skills you've archived; archived skills are excluded from the list by default.
- **Date range picker** and **provider rail** — same controls as the rest of the dashboard; scope what's shown.
