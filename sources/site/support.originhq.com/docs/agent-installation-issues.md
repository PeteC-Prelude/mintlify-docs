# 

Agent Installation Issues

This section covers errors and failure modes encountered while installing the Origin agent, and the steps to resolve them.

---

## 

Topics

- [Origin agent fails to install — error -1073741515 (Undefined)](https://support.originhq.com/docs/origin-agent-fails-to-install-error-1073741515) — missing Microsoft Visual C++ Redistributable on the target endpoint.
- [macOS agent installs but no AI events are captured](https://support.originhq.com/docs/macos-agent-installs-but-no-ai-events-are-captured) — Origin Activator network extension was not approved during manual installation.
- [Troubleshooting Network Connectivity](https://support.originhq.com/docs/troubleshooting-network-connectivity) — required Prelude endpoints and how to verify reachability on Windows and macOS.
