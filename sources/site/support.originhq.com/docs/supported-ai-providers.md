# Source: https://support.originhq.com/docs/supported-ai-providers

Origin provides visibility into traffic from the following AI providers and coding tools:

| Provider | Supported Applications |
| --- | --- |
| Anthropic | Browser (claude.ai), Claude code, Claude desktop, Claude cowork |
| OpenAI | Browser (chatgpt.com), ChatGPT desktop, Codex |
| Google | Browser (gemini.google.com), Gemini CLI |
| Cursor | Cursor desktop, Cursor CLI |
| Microsoft | Browser (copilot.microsoft.com), M365 app support |
| OpenRouter | Browser (openrouter.ai/chat) |
| Perplexity | Browser (perplexity.ai) |

 

To capture traffic from AI providers not in this list, you can define custom capture rules. See [Custom AI Providers](https://support.originhq.com/docs/origin-console-setup#capture--custom-ai-providers) in the Initial Setup guide.
