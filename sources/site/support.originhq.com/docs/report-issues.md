# Source: https://support.originhq.com/docs/report-issues

Use the **Report Issues** view to send a bug report or a feature request directly to the Origin team. Reports include the endpoint context you select plus any attachments you add, so the team has what they need to reproduce or scope the work without follow-up.

![Report Issues — Send feedback to Origin](https://files.readme.io/8dfd8d8d4ddf0dbc93c7d88a2cb790c7b1102b5623ea6bb097fb545dc333004e-Report-Issues.png)

## 

At a glance

- **Bug / Feature request** toggle (top right of the header) — picks the type of report. The form fields and the submit button label adjust to match.
- **Title** — short one-line summary of the issue or request.
- **What were you trying to do?** — the goal or task you were working on when the issue happened.
- **What happened?** — the actual behavior, including any error states you saw.
- **What did you expect?** — the behavior you were expecting instead.
- **Steps to reproduce** — ordered list of what you did so the team can reproduce it on their side.
- **Context → Affected Endpoint** (right rail) — search and pin a specific endpoint to the report. Optional, but helps the team filter to the right host on their side.
- **Attachments** (right rail, up to 10) — drag-drop or click _Choose files_. Accepts images, text, PDFs, JSON, zip, gzip, and tar.
- **Submit bug** / **Submit feature request** — sends the report. The button label tracks the toggle at the top.
